How to use

Quick start

  1. Current: dictate or paste today’s measurements as you normally would, with no priors.
  2. Prior: paste the prior study’s measurements. Pasting the whole prior report is fine; only the aortic lines are used.
  3. Check the dots, then press Copy and paste the output into your report.

Optional: type the prior study in Prior study (e.g. “CTA 08/16/2024”). The header then reads “(prior values from CTA 08/16/2024 in parentheses)”.

Example

The prior has its own older priors in parentheses and a graft note. Those are handled automatically: old priors are dropped and matching ignores the “(graft)” note.

Numbers only (fastest)

Paste the prior, then type just today’s numbers in order into Numbers only and press Enter. The tool writes the Current block using the prior’s labels, including notes like “(graft)”.

  • Separate numbers with spaces or commas. Write multi-dimension values as 39x37x44 or 39 x 37 x 44.
  • Type - to skip a line (for example, to drop Sinus of Valsalva).
  • With no prior pasted, the standard 10-line template is used (Sinus through Infrarenal).
  • Text-only prior lines, such as “Status post aortic valve replacement.”, are carried over and don’t use up a number.

Reading the dots

Green: matched to the prior; the change is under 3 mm.
Amber: no prior was found for this level, or the line was left exactly as dictated because it already has a comparison or extra text (e.g. “44, unchanged compared with…”).
Red: check this line. Any dimension changed by 3 mm or more (real growth or a typo), a value is in cm, or the same level appears twice.

Hover over a line to see the reason. A green check at the top means nothing is red.

What it understands

  • Notes in labels: “Sinotubular junction (graft)” matches “Sinotubular junction”. Your current labels are kept exactly as written.
  • Other templates: “Aortic root at the sinus”, “Distal ascending aorta”, “Aortic arch”, “Proximal descending thoracic aorta” and “Distal descending thoracic aorta at the hiatus” map to the matching levels.
  • Full prior values kept: 42 (40 x 38), with “mm” removed.
  • Deleted lines: if you remove a level (often Sinus of Valsalva), its prior is not used and is listed under the output as “Not used from prior”.
  • Spacing: spacing is flexible on both sides, e.g. 27(27) or double spaces.

FAQ

Does anything leave this computer?

No. The page makes no network connections. Open tabs are remembered in this computer’s browser so a refresh doesn’t lose them. Use Reset or close the tab (×) when you’re done with a case.

What are the tabs for?

Each tab is a separate case. + adds one, double-click a tab’s name to rename it, and × closes it. Reset clears only the tab you’re on.

A line didn’t get a prior. Why?

Either the prior didn’t have that level (common for suprarenal/infrarenal), or the label wasn’t recognized. If a label you use often isn’t recognized, send it over and it can be added.

Why was a line left as dictated?

If you already dictated a comparison on that line, e.g. “48 (45 on 04/20/2011)” or “44, unchanged compared with…”, the tool won’t overwrite it.

Copy didn’t work.

Click in the output, select all (Ctrl+A) and copy (Ctrl+C), or try Chrome or Edge.
